# Network progressive detail presentation contract

Pattern reports retain their producer verdict, group ordering, coverage and next-check semantics. Opening a group now mounts its explanation, qualified cause hypothesis, uncertainty and next checks **without** mounting example facts or measurements.

- Select one retained representative example. The bounded selector includes every supported retained example (up to the existing ten-example admission limit), not only the former three displayed examples. Labels use the original one-based position; selector values and numeric citations retain the producer's zero-based original index. Invalid siblings are not renumbered into source authority.
- The selected example exposes its original admitted raw facts. Choose RTT, packet spacing, TTL / Hop Limit, or full measurements. Only that measurement subtree is mounted. Full measurements means all measurement kinds for this one representative, never pooled group statistics.
- ICMP details use the same example selection, retain the existing event paging and omission semantics, and are mutually exclusive with expanded measurements. Changing examples retires event selection. Report-wide warnings remain in glance/coverage; example and metric qualification remains local and reachable. Missing, unsupported and zero-sample evidence is not a healthy result or a measured zero.
- Numeric citations retain the existing source/run/generation and precision checks, then select the exact original example and measurement kind. Ordinary issue citations open the explanation only. No extra reads or analysis actions are submitted by disclosure or selection.
- Selected examples use a nonmodal region at 1200 CSS pixels and wider and a labelled modal dialog below 1200. The selector and all measurement controls stay inside that same surface. Opening focuses its heading; only the narrow surface makes the background inert and contains focus. Escape and explicit Close remove the detail and return focus to the selector, or the same-source group heading for a citation whose AI invoker was retired. Unmount/source retirement never restores stale focus. Group/coverage/AI ownership remains exclusive. Source replacement retires local state before publishing children, including cached A→B→A. Closing display is not request cancellation; AI execution and saved-run behavior is unchanged.

The full Network job envelope leads with a visually compact title (complete accessible text is retained), status and report. The report reading order is verdict → actual coverage limitations → priority next check → up to three observations → overall counts and qualified cause hypothesis. All quantities and prose retain their existing meanings. Work information lazily exposes the complete job name/IDs, note, terminal processing timeline and source. Terminal job warnings are also rendered in full outside disclosure after the report; no unknown prose is classified as harmless or operational. The exact controller `apply_job_packet_limit` warning additionally yields a concise localized capture limitation before the report, preserving the literal retained/excluded packet counts without numeric coercion. This applies even to saved/legacy reports that lack the matching coverage qualifier. Original text remains available both outside disclosure and in Work information. Active phase/progress/cancel, restart-incomplete alert and cancellation errors remain visible. Network work labels share the report language state. C2/DDoS business and lifecycle paths are unchanged.

A Network-local detail surface adapts the existing candidate panel pattern because the shared component has candidate-specific fixed IDs and fallback targets. The shared component, detail-owner context and global CSS are unchanged. Responsive tests cover narrow-only inert/Tab containment, desktop freedom, resize while focus is outside, Escape/Close, source-retired callbacks, citation fallback and overflow. The 200% reflow proxy resizes a 1280×900 CSS viewport to 640×450, with an additional 320-pixel check; it does **not** claim native browser zoom or substitute a DPR-only change. Full raw measurement traversal remains separate from the reflow probe.

Tests that formerly expected three simultaneously mounted measurement blocks now visit those examples sequentially. Existing fact, quality, warning, maximum-corpus, keyboard and request-method assertions remain; no producer limit or deadline is relaxed. New browser traversal visits all 100×10 producer-retained examples at both 1280 and 390 pixels in English and Korean, checking the mounted document stays below 500 elements and saving named overview/detail screenshots. This is intercepted-transport browser evidence, not deployed-service or screen-reader acceptance.
